# Gerador de QRcode para E-commerce

Desafio DIO - Projeto Node.js para gerar QRcodes e gerenciar senhas.

## Sobre

Kit de utilidades escalável para e-commerce com funcionalidades de geração de QRcode e gerenciamento de senhas.

## Como Usar

### Instalação

```bash
npm install
```

### Executar

```bash
npm start
```

## Funcionalidades

- 🔐 Gerador de senhas seguras
- 📱 Gerador de QRcodes
- 🏗️ Arquitetura em camadas

## Tecnologias

- Node.js
- npm
